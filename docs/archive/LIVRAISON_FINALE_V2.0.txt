## 💡 5 CHOSES À SAVOIR

### 1. 5 Modules indépendants
Chaque module peut fonctionner seul:
```javascript
GestionEleves.inscrireEleve(...)        // Fonctionne toujours
GestionScolarites.enregistrerPaiement() // Fonctionne toujours
```

### 2. Dual storage (localStorage + Firebase)
- **Développement**: localStorage (pas besoin Firebase)
- **Production**: Firebase + localStorage fallback

### 3. Matricules auto-générées
- Élèves: STU-ABC123 (automatique)
- Factures: FAC-XYZ789 (automatique)
- Paiements: PAY-DEF456 (automatique)

### 4. Devise: Franc Guinéen (Fr)
- Tous montants formatés: "50 000 Fr"
- Localization: FR-FR

### 5. Zéro dépendances externes
- JavaScript pur (pas Bootstrap, jQuery, etc.)
- HTML5/CSS3 natif
- Fonctionne offline (localStorage)
