## 🆘 Ça ne marche pas?

**Erreur 1: Page blanche**
```
→ Vérifier fichiers présents
→ F12 (console) chercher erreurs rouges
→ Recharger page (Ctrl+R)
```

**Erreur 2: Modules pas visibles**
```
→ Vérifier login admin
→ Menu doit être visible à gauche
```

**Erreur 3: localStorage error**
```
→ Vider cache navigateur
→ Recharger page
```

## 💡 PRO TIPS

### Raccourcis clavier
```
F12         → Ouvrir console (pour debug)
Ctrl+R      → Recharger page
Ctrl+Shift+Delete → Vider cache
```

### Console commands
```javascript
// Voir modules chargés
window.GestionEleves
window.GestionScolarites
window.GestionDepenses

// Voir données sauvegardées
localStorage.getItem('eleves')
localStorage.getItem('factures')
```

### Parcourir pages
```
Menu → Finances V2 → [Module]
Ou accès direct:
navigate('gestion-eleves')
navigate('gestion-scolarites')
navigate('gestion-depenses')
navigate('tableau-bord-finances')
navigate('gestion-notifications')
```
