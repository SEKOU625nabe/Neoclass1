🆘 DÉPANNAGE RAPIDE

Erreur: "Finance system not found"
→ Attendre que tous les modules se chargent (2-3 secondes)
→ Rafraîchir la page (F5)

Les données ne s'affichent pas?
→ Ouvrir la console (F12)
→ Vérifier qu'il n'y a pas d'erreurs
→ Réinitialiser localStorage: localStorage.clear()

Dashboard vide?
→ Vérifier que JavaScript est activé
→ Vérifier la console pour les erreurs
→ Essayer avec un autre navigateur

Plus de questions?
→ Consulter INSTALLATION_ET_CONFIG.md → Section Dépannage
