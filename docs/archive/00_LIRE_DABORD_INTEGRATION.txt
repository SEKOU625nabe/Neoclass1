    ├─ saveOperation() → Firestore

    └─ schools/{schoolId}/
       ├─ finance_operations/ (Toutes les opérations)
       ├─ finance_budgets/ (Tous les budgets)
       ├─ finance_team/ (Tous les membres)
       ├─ finance_reports/ (Tous les rapports)
       └─ finance_logs/ (Audit trail complet)

💾 PERSISTANCE DES DONNÉES
════════════════════════════════════════════════════════════════════════════

DOUBLE SAUVEGARDE AUTOMATIQUE:

Niveau 1: Firebase Firestore
  ✓ Source de vérité primaire
  ✓ Cloud storage (sécurisé, backupé)
  ✓ Accessible de n'importe où
  ✓ Synchronisé entre utilisateurs
  
Niveau 2: localStorage
  ✓ Backup local dans le navigateur
  ✓ Accès offline
  ✓ Synchronisation automatique quand connexion revient
  ✓ Fallback si Firebase inaccessible

RÉSULTAT:
  ✅ Les données ne sont JAMAIS perdues
  ✅ Fonctionne même hors ligne
  ✅ Sync transparente quand online
  ✅ Aucune perte de donnée en cas d'erreur

AUDIT TRAIL:
