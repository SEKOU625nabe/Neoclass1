💡 TIPS IMPORTANTS
═════════════════════════════════════════════════════════════════════════════

NE PAS commiter:
├─ google-services.json (secrets!)
├─ neoclass-key.jks (clé privée!)
├─ .env (variables locales)
└─ capacitor.config.json avec données privées

Version code:
├─ Doit être incrémentée à chaque build
├─ Format: integer (1, 2, 3, ...)
└─ Play Store refuse downgrade version

Testing avant Play Store:
├─ Tester sur VRAI appareil
├─ Tester sur différentes versions Android
├─ Tester offline mode
└─ Vérifier permissions

Post-publication:
├─ Monitor Play Store console
├─ Répondre aux reviews
├─ Corriger bugs signalés
└─ Maintenir mise à jour
