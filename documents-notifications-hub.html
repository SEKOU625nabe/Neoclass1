À Propos

🎯 Objectif

Cette nouvelle intégration ajoute deux fonctionnalités majeures au système Neoclass:

  • Gestionnaire de Documents - Les écoles peuvent organiser et partager leurs documents
  • Système de Publicités - L'admin peut envoyer des notifications ciblées
  • Synchronisation en temps réel - Firestore + localStorage
  • Analytics complets - Suivi des téléchargements et clics

📂 Gestionnaire de Documents

Les écoles peuvent créer des catégories personnalisables et ajouter des documents. Chaque document peut avoir une visibilité définie (école, parents, public).

// Exemple: Créer une catégorie documentManager.createCategory('Financier', 'Documents financiers de l\'école') .then(category => console.log('Catégorie créée:', category))

📢 Système de Publicités

L'administrateur peut créer des publicités ciblées vers des audiences spécifiques (écoles, parents, professeurs, étudiants). Chaque publicité a un statut (brouillon, programmé, actif, terminé) et des statistiques (vues, clics, lectures).

// Exemple: Créer et publier une pub const ad = await notificationManager.createAdvertisement({ title: 'Nouvelle fonctionnalité', content: 'Découvrez notre nouvelle système de paiement', targetAudience: ['school', 'parent'] }); await notificationManager.publishAdvertisement(ad.id);

🔄 Synchronisation

Tous les documents et notifications sont synchronisés en temps réel avec Firestore. Un système de sauvegarde en localStorage permet le fonctionnement hors ligne.

  • Firestore - Base de données principale
  • localStorage - Synchronisation offline
  • Auto-sync - Synchronisation automatique
  • Sécurisé - Permissions par rôle

Cas d'Usage

📚 Cas 1: École partage des documents avec les parents

1. L'école crée une catégorie "Bulletins"
2. Ajoute les bulletins des élèves
3. Définit la visibilité à "Parents"
4. Les parents reçoivent une notification
5. Les parents peuvent télécharger les bulletins

📢 Cas 2: Admin notifie les écoles d'une mise à jour

1. Admin crée une pub: "Nouvelle fonctionnalité de paiement"
2. Cible: Écoles
3. Priorité: Normale
4. Les écoles reçoivent la notification
5. Admin voit les statistiques de lecture

⚠️ Cas 3: Alerte système urgente

1. Admin crée une pub: "Panne système imminente"
2. Type: Avertissement
3. Priorité: Urgente
4. Cible: Tous les utilisateurs
5. Les notifications apparaissent en priorité
