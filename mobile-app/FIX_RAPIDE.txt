❓ ERREURS COURANTES:
═════════════════════════════════════════════════════════════════════════════

"Cannot find module": 
→ npm install

"node: command not found":
→ Node.js non installé (https://nodejs.org)

"Already in use":
→ Le port 8000 est occupé
→ Changez le port dans server.js (ligne 3)

Erreurs Firebase:
→ Vérifiez que vous êtes sur http://
→ Appuyez Ctrl+Shift+R (cache)

"Connection refused":
→ Vérifiez que server.js est en cours d'exécution
