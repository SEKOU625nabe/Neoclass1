🚀 POUR DÉMARRER
═══════════════════════════════════════════════════════════════════════════════

1. LIRE (5 minutes)
   └─ cat QUICK_START.md

2. INSTALLER (5 minutes)
   ├─ chmod +x setup.sh
   └─ ./setup.sh

3. CONFIGURER FIREBASE (10 minutes)
   ├─ Créer projet sur https://console.firebase.google.com
   ├─ Télécharger google-services.json
   ├─ Placer dans android/app/
   └─ Mettre à jour www/app.js

4. TESTER (5 minutes)
   ├─ npx capacitor run android
   └─ Ou ouvrir Android Studio

5. BUILDER POUR PLAY STORE
   ├─ chmod +x build-release.sh
   └─ ./build-release.sh

6. DÉPLOYER (voir DEPLOYMENT_GUIDE.md)
   ├─ Créer Google Play account
   ├─ Préparer assets (icônes, screenshots)
   ├─ Remplir listing
   └─ Soumettre AAB
