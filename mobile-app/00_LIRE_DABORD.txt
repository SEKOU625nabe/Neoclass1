🚀 DÉMARRAGE EN 3 ÉTAPES
════════════════════════════════════════════════════════════════

1. INSTALLER
   cd mobile-app
   npm install
   npx capacitor add android
   npx capacitor sync android

2. CONFIGURER FIREBASE
   - Créer compte Firebase (gratuit)
   - Télécharger google-services.json
   - Placer dans android/app/
   - Mettre à jour www/app.js avec clés

3. TESTER
   npx capacitor run android
   OU
   Ouvrir Android Studio et cliquer "Run"

🎯 POUR PLAY STORE
════════════════════════════════════════════════════════════════

Avant soumission, vous devez:

1. ✅ Configuration Firebase complète
2. ✅ Tester sur Android réel
3. ✅ Préparer:
   - Icône 512x512 PNG
   - 2-8 screenshots (1080x1920)
   - Description App Store
   - Politique privée URL
   - Email support

4. ✅ Générer clé de signature:
   keytool -genkey -v -keystore neoclass-key.jks ...

5. ✅ Build AAB:
   chmod +x build-release.sh
   ./build-release.sh

6. ✅ Créer compte Google Play ($25 one-time)

7. ✅ Soumettre pour review (24-72h)
